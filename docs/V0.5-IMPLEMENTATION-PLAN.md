Status: requirements baseline at `b1345d9`. This plan derives scope from `ROADMAP.md` and
`PRODUCT-SPECIFICATION.md`; it does not move later milestones into v0.5 or claim human acceptance.

Closure status is maintained in `V0.5-CLOSURE-AUDIT.md`. As of 2026-09-15, canonical Live quick

and exercised credential rotation are human accepted. The matrix below remains the implementation

## Architectural boundary

All work remains in the canonical SwiftUI application through `BudgetApplicationServices` and
provider-neutral repository contracts. The Live implementation uses Budget Server and the
Deterministic implementation remains an ephemeral fixture. No view may select a provider. Exact money
remains signed `Int64` minor units, and the existing allocation, card-reserve, transfer,
reconciliation, scheduling, authorization, and audit engines remain authoritative.

## Explicitly deferred by the roadmap

- Comprehensive reporting-family expansion is v0.6; v0.5 adds only payee history/statistics and the
  filters needed by its transaction browser.
- Guided household UX and permission-management redesign are v0.7; v0.5 enforces existing server
  scopes and prevents transaction/payee leakage.
- Scenarios are v0.8.
- Consumer server manager, backup/restore UI and portability delivery are v0.9; recovery hardening is
  v0.95.
- Bank connectivity and import posting are post-v1.0 unless the roadmap changes. Payee aliases added
  now are a domain foundation, not authorization to implement imports.
- Production Local Device/SQLite and Dropbox providers are required product direction but are not
  assigned to v0.5.
- AI/OCR categorization is not v0.5. Default-category behavior is deterministic and confirmable.

## Stop conditions carried into implementation

Stop rather than guess if void reversibility, duplicate transfer behavior, attachment retention,
payee punctuation equivalence, bulk operation membership, or transaction classification would alter
financial meaning beyond the specification. No migration may merge ambiguous legacy payees or delete
transaction history.
