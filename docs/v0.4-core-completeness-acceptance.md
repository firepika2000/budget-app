## Definition of "core complete"
A live user can, end-to-end (discover → use → persist → reload → propagate):
1. Open any account and see its **transaction register** with running/cleared balances, and add/edit within it.
2. Create/edit a **target** on a category and watch progress + underfunded + Auto-Assign respond.
3. Create a **scheduled/recurring** transaction and see it in the forecast and materialize.
4. Enter/edit/delete/split/transfer transactions and see all derived state update (already met).
5. Reconcile accounts (already met).
6. Use credit cards with correct reserve accounting (already met).
7. Explore reports with ranges/filters and drill to transactions, editing in place (already met; donut visualization to restore).
8. Operate the household/delegation/approval system (already met; exceeds baseline).
