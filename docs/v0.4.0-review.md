# v0.4.0 review

## Release intent

v0.4.0 is the architecture-correction and functional-completion milestone. The same SwiftUI Home, Plan, Activity, Accounts, Insights, request, household, and editing views now serve authenticated self-hosted data and deterministic simulator data.

## Completed gates

- Backend authorization and ledger suite: 64 tests pass.
- Swift financial/API package: 36 tests pass.
- Native iOS deterministic workflow suite: 11 tests pass on iPhone 15 Pro Max, iOS 17.5.
- Alembic migrations upgrade through 0014, downgrade to 0011, and re-upgrade successfully on a clean SQLite verification database.
- Delegated authority is pre-funded, conserved, bounded, optimistic-concurrency checked, and enforced independently of UI visibility.
- Cash and credit reconciliation have distinct Ready-to-Assign consequences; adjustments require structure authority and stale cleared balances conflict.
- Production transaction editing includes exact splits and metadata, with immutable before/after/delete audit records.
- Funding-request approval, partial approval, changes requested, rejection, and action history use the live backend state machine.
- Insights ranges, filters, drill-through, edit, and refresh are wired in the shared product.

## Human review gate

Before tagging or enabling any external financial integration, perform both simulator walkthroughs in `docs/simulator-demo.md` and an authenticated run against a disposable self-hosted database. Confirm wording, empty states, accessibility, dark mode, and the intended owner/member privacy choices.

Bank synchronization is deliberately absent. No credential aggregation, institution connection, transaction import, or external financial provider is authorized by this milestone.
