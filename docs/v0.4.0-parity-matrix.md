## Client → server contract (spot-check of v0.4 additions)

| Client method | Server route | Contract |
|---|---|---|
| `updateTransaction` | `PUT /transactions/{id}` | `TransactionUpdate == TransactionCreate`; full-object replacement; client sends all fields incl. flag/tags/attachment. ✅ |
| `deleteTransaction` | `DELETE /transactions/{id}` | 204; reserve events + delete history handled. ✅ |
| `transferAllocation` | `POST /allocation-transfers` | `expected_allocation_version` sent. ✅ |
| `decideFinancialRequest` | `POST /requests/{id}/decision` | version + source category sent. ✅ |
| `reconcileAccount` | `POST /accounts/{id}/reconcile` | client sends `expected_cleared_balance_minor` (from loaded cleared txns). ⚠️ computed without a `through_date` filter — matches server only for the default (today) through-date (O-1/edge). |
| `spendingReport`/`incomeSpendingReport` | `GET /reports/*` | inclusive dates; filters transmitted; drill-down IDs preserved. ✅ |
| `commitSmartFunding` | `POST /smart-funding` | delegated 403 guard server-side. ✅ |
| `delegatedBudget` | `GET /delegated-budgets/me` | 404 when no policy; client `try?` → nil (can't distinguish transient error, O-1). ⚠️ |
| Error bodies | all | structured `detail` objects now surface their `message` (D-006). ✅ |

## Summary of new gaps opened by this audit

- **P1:** Targets cannot be created/edited in the app (server-ready). Needs an `APIClient.upsertTarget` + a Plan target editor. Mac-buildable only.
- **P1/P2:** Scheduled/recurring transactions have no client create/list.
- **P2:** Allowance management (create/issue/delete) not wired; only listing.
- **P2:** `cancelFinancialRequest` implemented but no UI entry point.
- **P2:** Hide Amounts appears demo-only; confirm whether live views mask amounts.
- **P3:** Export, allocation-history are intentionally desktop/admin-console features.

None of these are money-correctness or security defects — the server enforces all boundaries. They are client feature-completeness gaps requiring SwiftUI work and Mac verification, so they are documented here rather than half-built blind.
